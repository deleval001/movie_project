# movie_project
Analysis of 100+ movies watched by our household 


## Sample data

In the sample directory you can find a sample of the data used in this project. This data includes our ratings for the movie, the genre of the movie, who chose the movie, and other associated fields. 


For the analysis done in the notebooks a larger dataset was used that has not been included. 


## Data
Our analysis notebooks will read from here. If you want to run this analysis for your own data,  simply copy  the data into this directory and name it `movie_list.csv`.
